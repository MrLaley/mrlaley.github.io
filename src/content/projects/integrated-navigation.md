## Project Overview

Development of an embedded navigation system that calculates optimized routes to points of interest (POIs), running entirely on a Raspberry Pi configured as a server.

## Technical Highlights

* **Algorithmic Optimization:** Implementation of the A* algorithm for shortest-path calculation over a graph of points of interest, optimizing search through the use of specific heuristics.
* **Low-Level & Hardware:** Programming in C for direct communication with hardware components and optimization of critical processes close to the system.
* **Full-Stack Architecture:** Implementation of a robust backend in Java for routing logic and data management, along with a PostgreSQL database.
* **Web & Interface:** Creation of a reactive user interface in Vue.js (JavaScript), accessible via web environment and a physical touch screen.
* **Collaborative Engineering:** Intensive use of GitLab for version control and team coordination.

**Skills:** C (Programming Language), Assembly Language, and more.
