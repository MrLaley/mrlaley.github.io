## Project Overview

Development of a custom web platform for the RoboTeam Twente association, managing the project lifecycle under the SCRUM methodology to ensure iterative deliveries aligned with client needs.

## Key Contributions

* **Frontend Development:** Creation of a dynamic and responsive user interface using the Vue.js framework, prioritizing user experience (UX).
* **Backend & Security:** Construction of a robust Java server and integration of a SQL database. Implementation of security protocols, including SQL injection prevention and secure data management.
* **Agile Methodology:** Active role in an agile development team, participating in Sprints, Daily Stand-ups, and Code Reviews to ensure software quality.
* **Version Control:** Comprehensive code management and technical collaboration via GitLab, applying professional Git workflows.

## Achievements
Awarded **"Best Project Certificate"** by the EEMCS Faculty (University of Twente) among all participating teams in this project of the module.
