## Project Overview

Development of a comprehensive web platform in Vanilla JavaScript that simulates social media flow and automates real-time data analysis.

## Technical Highlights

* **Data Analysis & Classification:** Implementation of logic to categorize simulated posts by topic and sentiment analysis (positive, negative, ...).
* **Dynamic Data Visualization:** Creation of interactive charts to visualize key metrics, such as message volume by topic and post impact.
* **Pattern Recognition:** Development of specific functions to identify trends, such as the most shared message or highest-traction topics.
* **Vanilla JS:** Building the system without external frameworks, demonstrating a solid mastery of JavaScript, HTML, and CSS fundamentals.
* **Version Control:** Code management and team collaboration using GitHub.

**Skills:** Teamwork, Cryptography, and more.
